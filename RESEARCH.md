## 2. ФУНКЦИИ

Список из 20 функций, отсортированных от базовых к продвинутым.

### MVP (обязательные на старте)

**1. Генерация текстового контента с помощью AI**
Создание постов, подписей, заголовков, хэштегов на основе темы с учётом специфики платформы.
`Метка: MVP`

**2. Планировщик публикаций (scheduling)**
Задание точного времени и даты публикации. Бот автоматически публикует без участия пользователя.
`Метка: MVP`

**3. Контент-календарь**
Отображение запланированных публикаций в виде календаря/очереди на неделю/месяц.
`Метка: MVP`

**4. Адаптация контента под платформу**
Изменение длины текста, форматирования, хэштегов под требования конкретной платформы автоматически.
`Метка: MVP`

**5. Управление очередью (queue management)**
Постановка постов в очередь, заморозка, возобновление, удаление и перестановка задач.
`Метка: MVP`

**6. Шаблоны постов**
Готовые форматы: анонс, опрос, акция, цитата. Пользователь выбирает шаблон, бот формирует пост.
`Метка: MVP`

**7. Управление медиафайлами (медиабиблиотека)**
Хранение загруженных изображений и видео для повторного использования без повторной загрузки.
`Метка: MVP`

**8. Аналитика публикаций**
Охват, просмотры, реакции, клики, комментарии по каждому посту.
`Метка: MVP`

**9. Автопостинг из RSS-лент**
Подключение RSS-источников с автоматической публикацией новых материалов.
`Метка: MVP`

**10. Мультиплатформенная публикация**
Отправка одного поста в несколько каналов и платформ одновременно.
`Метка: MVP`

## 3. UX И СЦЕНАРИИ

### Сценарий 1. Подписка: первая встреча с ботом, онбординг, выбор тарифа

**Пошаговый флоу:**
1. Пользователь находит бота через реферальную ссылку, рекламу или каталог
2. Нажимает /start — бот присылает приветственное сообщение
3. Онбординг-квиз (3–4 вопроса): ниша, аудитория, цель, платформа
4. Бот показывает 1 бесплатный пример поста — пользователь видит результат ДО оплаты
5. Экран с тарифами (3 варианта) — бесплатный / Про / Бизнес
6. Оплата через Stars, карту (ЮKassa)
7. Мгновенный доступ после оплаты + подтверждение

**Что удобно:**
- Прогресс-бар онбординга («Шаг 2 из 4») — снижает тревогу
- Inline-кнопки вместо текстового ввода на каждом шаге
- Ценность показана до paywall — один пример поста
- Еженедельный тариф как точка входа: конвертирует в 5.4× лучше, чем годовой
- Три тарифа (не два) — средний работает как «якорь» (психология выбора)

**Что бесит пользователей:**
- Paywall на шаге 1 без демонстрации — конверсия падает до 1–3%
- Длинные текстовые стены в приветствии (800+ символов)
- Обязательная регистрация email/телефона («Зачем? Telegram же знает кто я»)
- Непонятные названия тарифов без конкретных цифр
- После оплаты — тишина 2–5 минут (пользователь нервничает)

**Типичные ошибки разработчиков:**
- Нет обработки ошибок оплаты — бот молчит при неудаче
- Онбординг не адаптирован под возврат — повторный /start показывает то же вводное сообщение
- Тарифы описаны с позиции функций, а не результата («30 постов» вместо «3 поста в день без усилий»)
- Нет follow-up через 24 часа если пользователь ушёл в середине онбординга

---

### Сценарий 2. Первое использование: цель → контент-план → пост → публикация

**Пошаговый флоу:**
1. После активации бот предлагает «Создать первый контент-план»
2. Бот спрашивает: тема/ниша (текстом), тон, платформа, частота — всё через inline-кнопки
3. Бот генерирует план на 7–14 дней со списком тем и форматами
4. Пользователь принимает план или корректирует темы
5. Тапает на тему → бот генерирует текст поста с превью
6. Кнопки: [Опубликовать сейчас] [Запланировать] [Переписать] [Короче] [Длиннее]
7. Первая публикация: бот просит добавить себя как администратора канала
8. Пост публикуется → бот подтверждает с ссылкой на опубликованный пост

**Что удобно:**
- Inline-кнопки «Одобрить / Изменить / Перегенерировать» под каждым постом
- Предпросмотр с реальным форматированием (жирный, курсив, эмодзи)
- Контекстные подсказки при генерации («обычно занимает 10–15 секунд»)
- Контекст сохраняется между сессиями — не нужно повторять нишу каждый раз
- Быстрые правки одной кнопкой вместо «напишите что изменить»

**Что бесит пользователей:**
- Запланированные посты не выходят вовремя (главная жалоба)
- Бот молчит после нажатия — непонятно, думает или завис
- AI генерирует одинаковые шаблонные тексты для всех ниш
- Инструкция по добавлению бота-администратора без кнопок/скриншотов — 40–60% уходят именно здесь
- Нет подтверждения с ссылкой после публикации — пользователь идёт проверять вручную

**Типичные ошибки разработчиков:**
- Нет `typing` индикатора при генерации (нужно отправлять каждые 4 секунды в цикле)
- Один промпт для всех платформ: Instagram Stories (300 символов, эмоционально) ≠ Telegram-канал (структурированно)
- Контент-план не учитывает что уже опубликовано — темы повторяются
- Нет тестового канала для предпросмотра перед реальной публикацией

### Сценарий 3. Реферальная / партнёрская программа

**Пошаговый флоу:**
1. Пользователь видит предложение после первой успешной публикации
2. Нажимает [Получить реферальную ссылку] или /ref
3. Бот генерирует `t.me/botname?start=ref_USER123`
4. Показывает условия: за каждого оплатившего — 1 месяц в подарок
5. Кнопки: [Скопировать ссылку] [Поделиться] [Готовый текст для друга]
6. При переходе реферала бот присылает: «Иван зарегистрировался по вашей ссылке»
7. После оплаты реферала: «Бонус начислен — +30 дней Pro»
8. Раздел /refs: переходы → регистрации → оплаты → накопленный бонус

**Что удобно:**
- Кнопка [Поделиться] открывает нативный forward Telegram — 2 тапа
- Готовый текст-шаблон для отправки другу — пользователю не нужно придумывать
- Дашборд с воронкой: «5 переходов, 2 оплаты, +14 дней Pro»
- Уведомления в реальном времени при каждом событии (переход/оплата)
- Двусторонняя выгода: реферер получает месяц, новый пользователь — расширенный триал
- Прогресс к следующей награде («Ещё 2 друга → месяц Pro»)

**Что бесит пользователей:**
- Бонус не начисляется или начисляется с задержкой — самая частая жалоба
- Непрозрачные условия (срок начисления не объяснён заранее)
- Нет личного кабинета рефералов — непонятно что происходит
- Минимальный порог вывода слишком высокий
- Реферальная ссылка ломается после обновления бота

**Типичные ошибки разработчиков:**
- Telegram не передаёт параметр `start` если чат уже существует — реферал не засчитывается. Решение: атрибуция только при первом `/start`
- Нет антифрода: один человек регистрирует несколько аккаунтов. Минимум: начисление только после первой оплаты
- Реферальная программа показывается на 2-й день вместо после первого успешного поста
- Нет автоматических уведомлений о событиях в воронке

## 5. МОНЕТИЗАЦИЯ

### Модели подписки

**Ключевые данные по конверсии (Freemius, 2025):**

| Модель | Конверсия в платных |
|---|---|
| Freemium → платная | 3–4% |
| Триал без карты (opt-in) | 18% |
| Триал с картой (opt-out) | 48–51% |
| Reverse trial | ~20% |

**Выводы:**
- Классический freemium умирает — 66% SaaS перешли на бесплатные триалы
- **Оптимум для аудитории "эксперты и малый бизнес":** 14-дневный триал без карты с полным функционалом
- Freemium имеет смысл только как маркетинговый инструмент: бесплатный план генерирует упоминания («ТОП-5 бесплатных инструментов») и органический трафик
- **Tiered pricing (Good-Better-Best):** три тарифа, средний работает как «якорь» — его выбирают чаще всего
- Резкие скачки цены между тарифами убивают конверсию. Шаги должны быть плавными
- **Гибридная модель** (фиксированная подписка + кредиты на AI-генерацию): +21% выручки vs фиксированные тарифы

### Реферальная программа

**Конверсия (ReferralCandy, 2026):**
- Медианная конверсия: 3–5%
- Топ-программы: 8%+
- Software/SaaS: 7.86%

**Что конвертирует лучше:**
- Cash-эквивалентные награды (кредиты, скидки) на **40% лучше** баллов и токенов
- Двусторонние награды (и реферер, и новый пользователь получают бонус)

**Примеры конкурентов:**

- ContentStudio: 30% комиссий за первый год
- Publer: 50% с первого платежа + 20% рекуррентно

**Для Telegram-бота:** Telegram Stars + официальный API аффилиатов позволяет платить комиссию внутри экосистемы без внешних выплат.

### Типичные ошибки монетизации

**1. Цена слишком низкая**
Слишком низкая цена позиционирует продукт как «игрушку». Прецедент низкой цены сложно изменить — повышение воспринимается как предательство. Признаки: конверсия из триала >30%, высокий объём поддержки на $1 выручки.

**2. Тарифы наказывают за рост**
Резкий скачок $39 → $119 при добавлении 1 пользователя (реальный кейс Everhour) — отток именно когда клиент растёт. Каждый следующий уровень должен ощущаться как выгодное предложение.

**3. Freemium без чёткой границы ценности**
Бесплатный план, в котором можно «почти всё» → низкая конверсия. Ограничивайте объём (количество постов, аккаунтов) или убирайте ключевую профессиональную функцию.

**4. Acquisition addiction**
Фокус на привлечении без работы с retention. «Если retention не сильный — продукт не создаёт достаточно ценности. Только после здорового retention стоит фокусироваться на acquisition» (Leadmore AI, $30k MRR).

**5. Неправильная метрика ценности**
«Цена за пользователя» не отражает ценность для SMM-ниши. Правильные метрики: количество аккаунтов/каналов, объём контента, количество сгенерированных единиц.

**6. Игнорирование LTV/CAC**
95% AI-проектов не зарабатывают из-за LTV < CAC. При подписке 1500 ₽/мес и сроке жизни клиента 10 месяцев → LTV = 15 000 ₽. Допустимые расходы на привлечение — до 5000 ₽.
