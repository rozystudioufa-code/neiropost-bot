## 1. О ПРОЕКТЕ

**Продукт:** neirobot — Telegram-бот, который самостоятельно пишет, планирует и публикует контент в социальных сетях (Telegram, ВКонтакте, Instagram).

**Суть:** Пользователь подключает бота один раз → задаёт тему, тон и частоту → бот генерирует посты с помощью AI и публикует по расписанию без участия пользователя.

**Ключевое УТП:** Нулевое трение входа — вся настройка происходит прямо в Telegram за 5 минут, без регистрации на сайте, без API, без кода.

---

## 2. ЦЕЛЬ И МЕТРИКИ УСПЕХА

**Единственная цель лендинга:** Привести пользователя к клику на кнопку запуска бота в Telegram.

Лендинг не продаёт подписку напрямую — он снимает барьеры и отправляет человека в бот, где происходит онбординг и оплата.

### Целевые метрики

| Метрика | Цель |
|---------|------|
| Конверсия (клик на CTA) | ≥ 8% |
| Scroll depth до секции тарифов | ≥ 60% |
| Bounce rate | ≤ 50% |
| Время на странице | ≥ 1:30 мин |
| LCP | < 2.0 сек |
| CLS | < 0.1 |

### Инструменты аналитики (подключить до запуска)

- **Microsoft Clarity** (бесплатно) — тепловые карты, записи сессий, scroll depth
- **Яндекс.Метрика** — цели на клик CTA, воронка

## 3. ЦЕЛЕВАЯ АУДИТОРИЯ

### Первичная аудитория — Владелец малого бизнеса

**Портрет:** 28–45 лет, есть Telegram-канал или группа ВКонтакте, ведёт сам или нанимает фрилансеров. Нетехнический. Заходит с телефона.

**Главная боль:** "Каждый день нужно что-то писать, но нет времени и идей. Фрилансеры срывают сроки, штатный SMM — дорого."

**Страхи:**
- Подписка-ловушка без возможности отменить
- Сложная настройка с кодом и API
- Контент будет шаблонным и одинаковым у всех
- Бот получит лишний доступ к каналу

**Что убедит:** "Без кода", "через Telegram", "7 дней без карты", реальный скриншот интерфейса, прозрачные цены.

---

### Вторичная аудитория — Блогер / Контент-мейкер

**Портрет:** 22–35 лет, ведёт личный Telegram-канал или Instagram, хочет масштабироваться без найма команды.

**Главная боль:** "Постить каждый день — выгораю. Хочу автоматизировать рутину, но сохранить свой голос."

**Что убедит:** "Авторский стиль", "редактирование перед публикацией", примеры постов в разных нишах.

---

### Третичная аудитория — SMM-агентство / Фрилансер

**Портрет:** Ведёт 5–20 клиентских каналов, ищет инструмент для масштабирования без роста команды.

**Что убедит:** Тариф "Агентство", мультиканальное управление, API, аналитика.

---

### Коммуникационный принцип

Язык страницы ориентирован на **первичную аудиторию** (владелец бизнеса). Никакого технического жаргона. Никаких слов: "синергия", "экосистема", "омниканальный". Говорить конкретно, с числами, от второго лица ("вы", "ваш канал").

### HEADER

**Состав:**
- Лого + название "neirobot" (слева)
- Навигация: Как работает / Тарифы / Отзывы (центр, скрыть на мобиле)

**Поведение:** Sticky. Всегда видим при скролле вниз и вверх. При скролле вниз — добавить `backdrop-filter: blur(12px)` и тонкую рамку снизу.

**Мобиль:** Лого + бургер-меню. В меню — навигация + CTA.

### БЛОК 6. ПРЕИМУЩЕСТВА (BENTO GRID)

**Задача:** Дифференциация. Ответить "Почему neirobot, а не конкуренты?"

**Layout:** Асимметричная Bento-сетка. Одна большая карточка (2×1) + четыре малых (1×1) + одна средняя (1×2).

```
[H2]
Всё, что нужно для автоматического контента

┌─────────────────────┬──────────┬──────────┐
│ 🧠 ИИ под вашу     │ 📅       │ 📊       │
│ нишу [БОЛЬШАЯ]     │ Авторас- │ Аналитика│
│                     │ писание  │ охватов  │
│ Бот обучается на   │          │          │
│ специфике вашего   ├──────────┼──────────┤
│ бизнеса и пишет    │ 📱       │ ✏️       │
│ в вашем стиле      │ 5+       │ Редакти- │
│                     │ соцсетей │ рование  │
├─────────────────────┴──────────┴──────────┤
│ 🌙 Работает без вас — даже в отпуске      │
│ Бот не болеет, не уходит в отпуск,        │
│ не просит повышения                        │
└────────────────────────────────────────────┘
```

**6 карточек — тексты:**

1. **🧠 ИИ под вашу нишу** (большая)
   Бот учитывает тематику вашего бизнеса, лексику аудитории и ваш тон голоса. Два канала в одной нише — разные тексты.

2. **📅 Автопубликация по расписанию**
   1, 3 или 5 постов в день — задаёте частоту один раз. Бот сам выбирает лучшее время.

3. **📊 Аналитика охватов**
   Видите, какие посты работают лучше. Бот учится и улучшает контент на основе статистики.

4. **📱 5+ соцсетей из одного места**
   Telegram, ВКонтакте, Instagram — один контент-план, публикация везде одновременно.

5. **✏️ Редактирование перед публикацией**
   Хотите — проверьте и поправьте. Не хотите — пусть выходит сам. Вы решаете.

6. **🌙 Работает без вас — даже в отпуске** (широкая)
   Бот не болеет, не уходит в отпуск, не просит повышения. Канал активен 365 дней в году.

### БЛОК 8. ОТЗЫВЫ

**Задача:** Снять сомнения через реальных людей с реальными результатами.

**Требования к отзывам (из экспертной оценки):**
- Обязательно: фото, имя, ниша, конкретные числа

## 7. АНИМАЦИИ И ИНТЕРАКТИВНОСТЬ

Все анимации должны уважать `prefers-reduced-motion` — при включённой настройке выключаться или заменяться fade.

### Обязательные анимации (MUST-HAVE)

| # | Анимация | Где | Приоритет |
|---|---------|-----|-----------|
| 1 | **Aurora gradient** — медленно движущийся цветной "туман" | Hero фон | Критично |
| 2 | **Typewriter** — смена слов в H1 ("публикует/пишет/планирует") | Hero заголовок | Критично |
| 3 | **Floating cards** — карточки "плавают" вокруг скриншота бота | Hero визуал | Критично |
| 4 | **Live-демо генерации** — текст появляется посимвольно | Блок 5 | Критично |
| 5 | **Scroll-stagger reveal** — карточки появляются с задержкой 120мс | Блок 6 Bento | Важно |
| 6 | **Animated counters** — числа считают при появлении в viewport | Блок 2 | Важно |
| 7 | **CTA hover glow** — кнопка светится при наведении + scale(1.03) | Все CTA | Важно |
| 8 | **Pinned scrollytelling** — шаги появляются при скролле | Блок 4 | Важно |
| 9 | **Micro-interactions** — hover на карточках, иконках, ссылках | Везде | Стандарт |

### Опциональные анимации (NICE-TO-HAVE)

| # | Анимация | Где |
|---|---------|-----|
| 10 | **Particle network** — нейросетевой фон | Hero или фон секции |
| 11 | **Magnetic button** — кнопка тянется к курсору | Финальный CTA |
| 12 | **Custom cursor** — фиолетовый blur-круг с lag | Весь сайт |
| 13 | **Lottie иконки** — анимируются при hover | Bento-карточки |

### Правила производительности

```css
/* Только GPU-свойства — никогда не анимировать layout-свойства */
/* Можно: transform, opacity */
/* Нельзя: top, left, width, height, margin, padding */

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 8. МОБИЛЬНАЯ ВЕРСИЯ

**Приоритет:** Мобильная версия разрабатывается первой. 70%+ целевой аудитории заходит с телефона.

**Брейкпоинты:**
```
mobile:  375–430px  (iPhone SE – iPhone Pro Max)
tablet:  768–1024px (iPad)
desktop: 1280px+
```

### Адаптация ключевых элементов

| Элемент | Desktop | Mobile |
|---------|---------|--------|
| Hero layout | Текст слева, визуал справа | Текст сверху, визуал снизу |
| H1 | 64–72px | 36px |
| Hero CTA | Кнопка + подпись | Кнопка во всю ширину |
| Bento Grid | 2–3 колонки | 1 колонка, приоритет 3 карточкам |
| Тарифы | 3 колонки | Горизонтальный скролл или стак |
| Floating cards | 3 карточки | Убрать или оставить 1 |
| Pinned scrollytelling | Включён | Отключён, заменить на простой список |
| Particle network | Включён | Отключён (performance) |

**Sticky CTA на мобиле:** Фиксированная кнопка внизу экрана с `safe-area-inset-bottom` для notch-устройств.

```css
.sticky-cta-mobile {
  position: fixed;
  bottom: 0;
  left: 0;
  right: 0;
  padding: 12px 16px calc(12px + env(safe-area-inset-bottom));
  background: rgba(7, 11, 20, 0.95);
  backdrop-filter: blur(12px);
  border-top: 1px solid rgba(255, 255, 255, 0.08);
  z-index: 50;
}
```
